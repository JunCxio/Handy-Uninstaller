# Handy Uninstaller

Windows x64 桌面程序。使用原生 Win32 窗口，无第三方 Rust 依赖。发布后可直接运行单个 `handy-uninstaller.exe`。

## 构建

安装 Rust 工具链后，在项目目录执行：

```powershell
cargo build --release
```

输出文件：`target/release/handy-uninstaller.exe`。

应用图标已嵌入可执行文件。更换 `assets/app.ico` 后，先运行 `python tools/make_icon_object.py` 更新资源对象，再重新构建；`assets/app.svg` 是可编辑的原始图形。

## 功能范围

- 枚举 HKLM、HKCU 的 64 位和 32 位卸载注册项，以及当前用户的商店应用；通过“桌面应用”和“商店应用”页签切换。
- 显示应用名称、版本、发布者、来源、安装时间和可取得的程序图标；点击列标题切换升序、降序，支持搜索和刷新。
- 可启停安装监控：每 5 秒检查卸载注册项与当前用户商店应用包，发现新增登记项时更新列表并提示；关闭程序后停止监控。
- 启动卸载前显示实际命令，并重新读取传统程序的 `UninstallString`，防止列表过期。
- 右键支持单项卸载和多选后的逐个卸载。桌面应用逐项启动卸载程序，并在确认前一项结束后处理下一项；商店应用依次执行卸载命令。卸载期间不能删除其他应用。
- 右键菜单还包含强制删除、删除条目、注册表条目和安装文件夹。删除条目只删除卸载登记项；注册表条目会在注册表编辑器中定位到对应项。
- 强制删除先逐页显示候选项，再要求最终确认。候选项包括明确的安装目录、指向该目录的快捷方式、名称完全一致的 AppData 或 ProgramData 目录与 `Software` 注册表键，以及卸载登记项。安装路径不明确或与其他登记应用共用时，不会将该目录列为删除候选项。卸载登记项最后删除；若前面的删除失败，则保留登记项。普通卸载完成且登记项消失后，可选择执行同一残留扫描和确认流程。

商店应用的枚举与卸载、快捷方式目标读取使用 Windows 自带的 PowerShell。商店应用图标从包清单解析，并由 Windows GDI+ 加载；包内没有可用图标时显示通用图标。商店应用没有传统卸载注册项，右键菜单中不适用的操作会禁用。当前筛选和强制删除规则是基于 Geek 逆向证据的保守实现：要求 `DisplayName` 和 `UninstallString` 非空，排除 `SystemComponent=1` 和带 `ParentDisplayName` 的条目；尚未证明与 Geek 的所有显示条件及残留匹配规则完全一致。强制删除不会扫描 MSI 痕迹，也不会按模糊名称删除其他文件或注册表项。

安装时间读取桌面应用卸载登记项中的 `InstallDate`（`YYYYMMDD`）；登记项没有日期或商店包无法提供日期时留空。无法从现有系统数据可靠取得应用的累计使用时间，因此界面不显示该列，也不再写入使用时间记录。

安装监控只检测已登记应用的变化，不跟踪安装器创建或修改的全部文件和注册表项。REA 对提供的 `geek.exe` 确认其为 Geek Uninstaller 1.5.5.185 免费版；当前分析环境没有可用的原生反编译后端，也未取得专业版程序，因此不能确认截图中专业版三项功能的内部算法。本项目实现的是上述可验证的对应行为，不声称与专业版完全一致。

单元测试：`cargo test`。窗口验证使用 `smoke.py`，该脚本检查列表、图标列表、页签、搜索、监控启停和右键菜单，不启动卸载或删除。
